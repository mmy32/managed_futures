# QPS vs baseline TSMOM: what changes at each stage, and where it lives in code

Status as of 2026-10-13. Draft for review. Paths are relative to this folder. Line numbers will drift as the code changes.

This is an older QPS-versus-TSMOM comparison. The current planned inverse-volatility versus HRP
comparison is defined in [docs/HRP_COMPARISON.md](docs/HRP_COMPARISON.md).

- **Baseline TSMOM**: Moskowitz-Ooi-Pedersen 2012 replication. Entry point: [run_tsmom_baseline.py](scripts/run_tsmom_baseline.py), config [tsmom_baseline.json](config/tsmom_baseline.json).
- **QPS**: the enhanced course strategy, tested against an always-long STATIC portfolio. Entry point: [run_research.py](scripts/run_research.py), which calls [run_risk_research.py](scripts/run_risk_research.py). Config [baseline_config.json](config/baseline_config.json) and [risk_config.json](config/risk_config.json).
- Both share one signal, risk, sizing and accounting framework, so the difference is mostly which components and settings are plugged in. QPS objects are assembled from config in [qps_baseline.py:27](src/backtest/qps_baseline.py#L27) `qps_components`.
