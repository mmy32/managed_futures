# Report Generation Pipeline

## Sources
1. `research/` — raw findings, data exploration, literature notes
2. `README.md` — project context, goals, setup

## Process
1. Gather findings from `research/` (chronological or by topic)
2. Pull project context from `README.md`
3. Draft report in `reports/<YYYY-MM-DD>-<topic>.md`

## Output
- Reports go in `reports/`
- Each report references its source research files
- Reports follow the project's writing guidelines (if defined)
